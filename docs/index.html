Scan in one click

Reads your Steam libraries, Epic manifests and Start Menu shortcuts, and skips tools like browsers and editors.

Real covers

Posters come from SteamGridDB with a free key. Without one, each game gets its own color.

Playtime

Opening it on Windows

  1. Run the .exe installer and follow the steps.
  2. If Windows says it protected your PC, click More info, then Run anyway.
  3. Open PTR Corporations and press Scan games & apps.

This appears because the app is free and not signed with a paid code-signing certificate. The build is the same one published on GitHub.

Opening it on a Mac

  1. Open the .dmg and drag PTR Corporations into Applications.
  2. Right-click the app, choose Open, then Open again. Only needed the first time.
  3. If macOS says the app is damaged, run this in Terminal, then open it again:
xattr -dr com.apple.quarantine "/Applications/PTR Corporations.app"
